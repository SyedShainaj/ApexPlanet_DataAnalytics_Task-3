
# Deep-Dive Analysis & Interactive Dashboarding

## 📌 Overview

This project was completed as part of my **Data Analytics Internship at ApexPlanet**. The objective was to perform a deep-dive business analysis, define key performance indicators (KPIs), and build an interactive dashboard to visualize business insights.

## 🎯 Objectives

* Analyze business data and identify trends.
* Define core KPIs for performance measurement.
* Perform customer and revenue analysis.
* Build an interactive dashboard for decision-making.

## 🛠️ Tools & Technologies

* Python
* Pandas
* NumPy
* Plotly
* Dash
* Google Colab

## 📈 Key Performance Indicators (KPIs)

* Total Revenue
* Average Order Value
* Conversion Rate
* Customer Churn Rate
* Total Customers

## 📊 Dashboard Features

* Revenue Analysis by Region
* Revenue Distribution by Category
* Monthly Revenue Trends
* Customer Churn Analysis
* Funnel Analysis
* Customer Segmentation
* Interactive Visualizations
